# 网页版加减乘除计算器 - 产品需求文档

## 1. 产品概述

一个简洁的网页版四则运算计算器，前端提供直观的操作界面，后端负责执行运算逻辑并返回结果。
- 目的：让用户通过浏览器即可完成加、减、乘、除基本运算
- 目标用户：需要快速进行简单数学计算的普通用户

## 2. 核心功能

### 2.1 用户角色
无需区分角色，所有访问者均可直接使用

### 2.2 功能模块
1. **计算器主页面**：数字输入、运算符选择、运算结果展示、历史记录

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 计算器主页面 | 显示屏 | 实时显示当前输入的表达式与运算结果 |
| 计算器主页面 | 数字键盘 | 0-9 数字按钮、小数点按钮 |
| 计算器主页面 | 运算符按键 | 加(+) 减(-) 乘(×) 除(÷) 等于(=) 清除(C) 退格(⌫) |
| 计算器主页面 | 历史记录 | 显示最近若干条计算历史，可清空 |
| 计算器主页面 | 错误提示 | 除数为 0 等异常时显示友好提示 |

## 3. 核心流程

用户点击数字与运算符组成表达式 → 点击等号 → 前端将表达式发送到后端 `/api/calculate` → 后端解析并计算 → 返回 JSON 结果 → 前端展示结果并追加到历史记录。

```mermaid
flowchart TD
    "A[用户输入数字/运算符]" --> "B[点击等号提交]"
    "B" --> "C[前端POST /api/calculate]"
    "C" --> "D{后端校验与计算}"
    "D"|"成功"| "E[返回结果JSON]"
    "D"|"失败(如除0)|" "F[返回错误信息]"
    "E" --> "G[显示结果 + 写入历史]"
    "F" --> "H[显示错误提示]"
```

## 4. 用户界面设计

### 4.1 设计风格
- 色调：莫兰迪色系（低饱和度灰调，温柔雅致）
- 主色调：雾灰蓝 (#A8B5C4) 背景 + 灰豆沙 (#C8A294) 强调
- 辅助色：米白 (#EDE6D9) 文字、灰绿 (#8FA89A) 次级强调、暖灰 (#D6CFC4) 中性色
- 按钮风格：圆角矩形带轻微阴影，按下时压感动画
- 字体：标题用 `Sora`（数字显示富有几何感），正文用 `Inter`
- 布局：居中卡片式布局，左侧显示屏 + 历史记录，右侧按键网格
- 图标风格：极简线性符号，避免 emoji

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|--------|
| 计算器主页面 | 显示屏 | 大字号 LCD 风格，等号按下时数字弹跳动画，莫兰迪灰豆沙色调 |
| 计算器主页面 | 按键网格 | 4×5 网格，悬停柔和过渡，等号按钮宽列高亮（灰豆沙色） |
| 计算器主页面 | 历史记录 | 侧栏滑入，逐条淡入动画，米白底色 |

### 4.3 响应式
- 桌面优先：宽度 ≥ 768px 时左右双栏布局
- 移动端：单栏纵向堆叠，按键放大，触摸友好

### 4.4 3D 场景
不适用
